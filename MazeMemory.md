## Abstract


Most multi-agent systems operate without a shared memory layer, meaning each agent maintains only its own private context and cannot access information gathered by others. In single-agent systems this limitation is irrelevant, but in multi-agent settings it leads to redundant computation, increased token consumption, and limited coordination between agents. For production environments, a shared memory architecture is therefore essential to reduce operational costs and enable effective collaboration.
To demonstrate the benefits of shared memory, this work proposes a maze-based environment in which multiple LLM-powered agents share a common memory space. Agents share their current locations and path information, and can query the memory to determine whether they are on an optimal route towards the maze exit based on their own position and the locations of other agents in the system. In addition, an observer agent is introduced to monitor the system and evaluate whether its guidance improves the overall performance of the group. The system is evaluated in terms of path optimality, token consumption, and redundant computation reduction across agents.


## Objetive

### General Objective:
The main contribution of this work is the design of a maze-based architecture to evaluate shared-memory agents. Building on this, the study demonstrates how memory sharing improves efficiency, reduces computational cost, and enhances coordination in multi-agent environments.

### Specific Objectives
    
1. To design and evaluate a set of metrics to measure how shared memory improves efficiency, reduces computational cost, and enhances coordination in multi-agent systems.

2. To compare the performance of multi-agent systems with and without shared memory, analysing differences in efficiency, coordination, and resource usage.

3. To analyse the impact of an observer agent on system performance by comparing scenarios with and without observer guidance.

### Research Questions

1. How does shared memory influence the performance of LLM-based multi-agent systems in terms of efficiency, cost, and coordination?
2. Does the inclusion of an observer agent improve coordination and reduce redundant computation in shared-memory environments?


## Methodology

The research adopts an experimental methodology to assess the effect of shared memory on the performance of LLM-based multi-agent systems. The experiments are conducted in a maze-based environment in which three agents are tasked with finding the exit under different coordination settings.

Three scenarios with increasing levels of memory integration are considered:
    • Baseline: agents operate independently, each maintaining their own memory, with no communication or shared memory.
    • Shared Memory: agents interact through a shared in-memory storage, allowing them to reuse information generated by others. While each agent maintains its own local memory, they also have access to a shared memory space for exchanging information.
    • Shared Memory + Observer agent: In addition to the shared memory store, an observer agent analyses the information available in the system and provides high-level guidance to support the navigating agents.

Each agent has access to the following tools:
    • get_location(): Returns the agent's current (x,y) position in the maze. 
    • get_distance_to_exit(): Returns the distance to the exit. The distance is reflect in step to the end based on their current position.

Besides, observator agent has access to the following tools:
    • get_insight(): it is invoked by an agent and performs the following: it reconstructs the path travelled by all agents in the system using the raw position data recorded at each timestep, and based on this global view of all routes, it provides a movement recommendation to the invoking agent.

To improve the reliability of the evaluation, the experiments are not limited to a single maze or a single execution. Instead, the study uses three maze instances, each representing a different configuration of paths and obstacles, and each scenario is executed 20 times per maze. This produces a total of 180 runs (3 maze instances × 3 scenarios × 20 executions each), allowing the analysis to capture both environmental diversity and the stochastic variability of agent behaviour.

To quantify the benefit of shared memory, the evaluation measures the extent to which duplicated work is avoided across agents. Redundant computation is defined as any cell visited by an agent that satisfies two conditions simultaneously: the cell was previously visited by another agent, and the cell does not form part of the visiting agent's optimal A* path calculated from its current position at the moment the first agent finds the exit. Exploration performed before the exit is discovered is not penalised, as agents are navigating an unknown environment and free exploration is unavoidable.
